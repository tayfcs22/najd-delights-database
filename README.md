# Najd Delights – Restaurant Database

## Project Overview
Najd Delights is a restaurant management database project developed using MySQL.

The database is designed to organize and manage restaurant information, including customers, staff, dishes, and orders.

## Database Tables
The project includes the following tables:
- Customer
- Staff
- Dish
- Orders
- Order_Details

## SQL Concepts Applied
- Database and table creation
- INSERT, UPDATE, and DELETE statements
- Primary and Foreign Keys
- Constraints
- Aggregate Functions
- GROUP BY
- JOIN Operations
- Subqueries
- Views

## Tools Used
- MySQL
- SQL
